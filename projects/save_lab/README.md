# Save Lab — ordinary M61 project

Open `save_lab.judasproj`, Play, or launch it in standalone. Original redistributable
fixtures from the current liquid, ragdoll and audio projects are reused with their
licenses. No privileged save path or new fluid/animation/audio algorithm.

- WASD/mouse: move/look; Space/C: launch or move through water.
- G: carry/drop the physical bucket; P: tilt; T: throw; wheel: carry height.
- V: disturb water. Q/E: paired reservoir transfers; Z/X: large-pool transfers.
- B: enter/leave physical ragdoll. M: crossfade. K: seek persistent music to 4 s.
- F6: choose slot A/B. F5: save (repeat to overwrite). F8: load selected slot.
- Escape: pause, choose slot, save/load/delete (repeat deletion to confirm),
  New Game/reload, resume or quit. Wait for **completed**, then quit entirely.

Resume loads native water/poses/music and script state; it is not a new game.
Load clears input edges and rebuilds UI with the menu closed. Master output level
remains a current-machine preference. Use Streamed Range for localized slot UI,
locale changes, travellers and genuinely unloaded-region revisit.

See `docs/M61_SAVES.md` and `docs/evidence/m61/RESULTS.md` for the measured contract.
